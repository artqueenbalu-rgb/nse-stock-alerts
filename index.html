🔗 Connect & Deploy to Your GitHub Repository

Your app pushes your configured symbols and target ₹ prices to watchlist.json on GitHub, and fetches the live NSE prices, 52W lows, and averages that GitHub Actions calculates.

Local Mode (Add Token in GitHub Tab to Sync)

🌐 Your Bookmarkable GitHub App URL (GitHub Pages)

Once you click 1-Click Deploy All Files & Host App below, bookmark this URL on your phone & laptop: https://artqueenbalu-rgb.github.io/nse-stock-alerts/

1. Configured watchlist.json

Contains your symbols, names, and target ₹ prices. GitHub fills in the live market metrics when it runs.


        


        

          

            

              
2. GitHub Workflow .github/workflows/market_alert.yml

              
            

            
Runs on GitHub, fetches NSE prices, saves them back to your repo so this app can read them, and sends push alerts.

          

          

        


        

          

            

              
3. Scanner Script nse_dip_predictor.py

              
            

            
Fetches 1-year NSE data via Yahoo Finance on GitHub, updates watchlist.json & alerts_history.json, and pushes alerts.

          

          

        


        

          

            

              
4. Dependencies requirements.txt

              
            

            
Python libraries installed automatically by GitHub Actions during each scan.
